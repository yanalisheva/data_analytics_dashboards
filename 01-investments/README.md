# Дашборд инвестиционных показателей сети за 2022–2023 гг.

## О проекте
Интерактивный дашборд для мониторинга инвестиций и прогнозирования
финансирования сети филиалов. Позволяет руководству видеть динамику
начислений и выплат, анализировать филиалы-лидеры и моделировать
открытие новых точек.

## Бизнес-задача
Руководству нужен единый инструмент для мониторинга инвестиций и
оперативного прогноза финансирования с возможностью сценария
"что будет, если открыть новый филиал".

## Что показывает
- Динамика начислений и выплат по месяцам
- Топ-5 филиалов по начислениям
- Прогноз финансирования до конца года с возможностью
  сценарного открытия нового филиала
